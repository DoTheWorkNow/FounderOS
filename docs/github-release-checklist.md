# GitHub Release Checklist

Use this checklist before publishing FounderOS as an open source repository.

## Repository Basics

- [ ] Confirm the repository root is the `FounderOS/` folder.
- [ ] Keep `README.md` at the repository root.
- [ ] Keep `LICENSE` at the repository root.
- [ ] Keep `CONTRIBUTING.md` at the repository root.
- [ ] Keep `AGENTS.md` at the repository root for AI agent instructions.

## GitHub Settings

- [ ] Add a short repository description.
- [ ] Add topics such as `founder`, `startup`, `obsidian`, `markdown`, `ai-agents`.
- [ ] Enable Issues if you want public feedback.
- [ ] Enable Discussions if you want community workflows and examples.

## First Release

- [ ] Check that every documented folder exists.
- [ ] Check that templates can be copied directly into working folders.
- [ ] Check that examples are complete enough for a new user to follow.
- [ ] Add a `v0.1.0` release once the structure feels stable.

## Nice To Have Later

- [ ] Add screenshots from Obsidian or VS Code.
- [ ] Add more example founder workflows.
- [ ] Add issue templates for template suggestions and workflow examples.
