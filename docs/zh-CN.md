# FounderOS 中文解释

FounderOS 的主入口保持英文，是因为这个项目希望面向全球创始人、indie hackers、AI builders 和 Markdown/Obsidian/Cursor 用户。

这个页面不是中文版 README，而是给中文读者的简短解释：FounderOS 是什么、为什么这样设计、以及如何开始使用。

## FounderOS 是什么

FounderOS 是一个 Markdown 优先的创业者操作系统。

它帮助你把创业过程里的零散内容分开管理：

- 原始想法
- 用户问题
- 市场研究
- 产品构思
- 商业模式
- 实验验证
- 创始人复盘

它不是一个 App，也不是复杂项目管理系统，而是一个可以直接放进 Obsidian、VS Code、Cursor 或 GitHub 的创业知识库结构。

## 为什么主项目用英文

FounderOS 的主题天然适合全球社区：

- solo founders
- indie hackers
- AI-assisted builders
- productivity and Obsidian users
- startup operators

这些社区主要分布在 GitHub、X、Hacker News、Reddit、Product Hunt 等英文语境里。主项目使用英文，更容易被全球用户发现、理解、复用和贡献。

中文解释会保留，但不会把项目主入口变成双语页面。这样可以兼顾全球传播和中文读者理解。

## 核心工作流

FounderOS 的基本节奏是：

```text
idea -> problem -> market -> product -> business model -> experiment -> decision
```

也就是说，一个想法不应该只停留在灵感层面，而应该逐步变成：

1. 谁的问题？
2. 这个问题是否真实、高频、强痛？
3. 市场和替代方案是什么？
4. 可以做什么 MVP？
5. 商业模式是否成立？
6. 最小验证实验是什么？
7. 根据证据做什么决策？

## 如何开始

1. 把所有未整理想法先放进 `00-Inbox/`。
2. 想法变清楚后，移动到 `01-Ideas/`。
3. 如果发现真实用户痛点，写进 `02-Problems/`。
4. 市场、竞品、趋势放进 `03-Market/`。
5. 产品方案和 MVP 放进 `04-Products/`。
6. 定价、渠道、收入模型放进 `05-Business-Models/`。
7. 访谈、测试、验证数据放进 `07-Experiments/`。
8. 复盘、原则、决策记录放进 `06-Founder-Notes/`。

## 和 AI Agent 一起用

FounderOS 很适合和 AI assistant 一起使用。你可以让 AI 帮你：

- 整理 `00-Inbox/` 里的原始想法
- 把一个模糊 idea 拆成用户问题和关键假设
- 根据访谈记录提炼痛点
- 设计最小验证实验
- 对市场研究做归纳和追问
- 建议下一步最小行动

项目里的 `AGENTS.md` 是给 AI agent 看的协作说明。

## 中文用户怎么用

如果你是中文用户，可以继续用中文写自己的笔记。FounderOS 的文件夹和模板保持英文，是为了让项目更适合开源传播；但你的实际内容完全可以是中文。

一个推荐做法是：

- 仓库和模板保持英文
- 自己的创业笔记用中文
- 对外分享和 GitHub 项目说明用英文

这样既不影响个人使用，也保留全球化传播空间。
